# Discord コマンド詳細リファレンス

本システムで提供される Discord スラッシュコマンドの詳細仕様です。

## コマンド一覧

### 🚀 /start
- **概要**: EC2インスタンスを起動し、FactorioサーバーがRCONを受け付けられる状態になるまで監視します。
- **挙動**: 
  - インスタンス起動後、`RCON_READY_CHECK_MAX_ATTEMPTS` と `RCON_READY_CHECK_INTERVAL_SECONDS` の設定値に基づいてポーリングし、RCONが応答した時点で完了通知を送信します（既定値では約2分）。
  - 完了メッセージにはサーバーのIPアドレスと参加パスワードが含まれます。

### 🛑 /stop
- **概要**: データを安全に保護しながらサーバーをシャットダウンします。
- **挙動**: 
  - `RCONセーブ` -> `カタログ更新` -> `Factorioサービス停止` -> `S3 Filesアンマウント試行` -> `EC2停止` の順で実行されます。
  - アンマウントは停止シーケンス内で実行されますが、実装上は `umount ... || true` で失敗を許容するため、同期完了の最終保証はS3側の反映確認と併せて運用してください。

### 📊 /status
- **概要**: サーバーの稼働状況をリアルタイムで表示します。
- **表示項目**:
  - インスタンスの状態（running / stopped / transition）
  - 接続用 IP アドレス
  - オンラインプレイヤー数およびプレイヤー名
  - 最終セーブ時刻とファイルサイズ
  - **同期ステータス**: DynamoDBのカタログとS3の実際の更新時間を比較し、アップロード中の場合は「(同期中)」と表示されます。

### 💾 /save
- **概要**: RCON経由で `/server-save` を実行し、即座にデータを保護します。
- **補足**: 実行後、DynamoDB上の「最終セーブカタログ」も更新されます。

### ⏳ /restore
セーブデータの履歴管理と復元を行います。

- **`/restore list`**: S3のバージョニング履歴から、過去のセーブポイントを一覧表示します。
- **`/restore select [version_id]`**: 指定したバージョンIDを `CopyObject` で同一キーへ再配置し、新しい current version として復元します。
  - ⚠️ **注意**: 復元はサーバーが「停止中」である必要があります。

### 🔑 /pass
- **概要**: 現在セッションで有効な参加パスワードを表示します。
- **挙動**:
  - 通常は DynamoDB の `ActivePassword` を参照し、起動処理中は「準備中」メッセージ付きで表示します。
  - `ActivePassword` 取得失敗時は `GAME_PASSWORD` 設定値へフォールバックします。

## 🔐 権限管理

`.env` の `RESTRICTED_COMMAND_STRINGS` に記載されたコマンドは、`ADMIN_USER_IDS` または `ADMIN_ROLE_IDS` に含まれるユーザーのみが実行可能です。

- デフォルトの制限対象: `start`, `stop`, `save`, `restore:select`
- 制限されているコマンドは、Discord上の説明文に自動的に **[管理者限定]** タグが付与されます。

---

## 🫥 本人限定（Ephemeral）表示

本人限定表示の対象は `.env` の `EPHEMERAL_COMMAND_STRINGS` で設定できます。  
既定では、閲覧系コマンドである `status`, `pass`, `restore:list`, `license` が設定されています。
